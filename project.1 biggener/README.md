# Customer Sales Analysis

## Project Overview

This project analyzes customer sales data using Python and Pandas to understand sales performance, customer behavior, product performance, city-wise sales, payment methods, and discount impact

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- CSV
- Data Cleaning
- Data Analysis
- Data Visualization

## Analysis Performed

- Calculated gross sales
- Calculated discount amount
- Calculated final sales after discount
- Analyzed product-wise sales
- Analyzed city-wise sales
- Analyzed payment-wise sales
- Analyzed customer-wise sales
- Analyzed average order sales
- Analyzed product-wise quantity
- Created sales visualizations

## Key Business Insights

- Laptop generated the highest product-level sales.
- UPI generated the highest sales among payment methods.
- City-wise final sales were compared after accounting for discounts.
- Customer-wise final sales were analyzed to identify high-value customers.
- Product-wise average final sales were compared to understand average order performance.
- Discount impact was analyzed by comparing gross sales with final sales.
