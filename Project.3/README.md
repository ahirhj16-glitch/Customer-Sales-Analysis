## Project Overview

This project analyzes customer sales data using Python and Pandas to understand sales performance, customer behavior, product performance, city-wise sales and payment methods

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- CSV
- Data Cleaning
- Data Analysis
- Data Visualization

## Analysis Performed

- Calculated gross sales
- Calculated discount amount
- Calculated final sales after discount
- Analyzed product-wise sales
- Analyzed city-wise sales
- Analyzed payment-wise sales
- Analyzed customer-wise sales
- Analyzed average order sales
- Created sales visualizations
